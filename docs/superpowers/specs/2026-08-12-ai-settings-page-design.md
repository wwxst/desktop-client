# AI 模型设置页设计

> 状态：当前实现设计
> 范围：工作区设置页中的 AI 模型配置

## 目标

把 AI 模型的全局连接配置从 AI 面板中移到独立设置页，视觉参考侧栏分组、右侧内容卡片的设置工作区。第一版只保留必要配置，不扩展温度、超时、网络测试或其他模型管理能力。

## 页面结构

- 侧栏底部齿轮进入“设置”工作区。
- 设置工作区左侧提供返回应用、搜索框和设置导航；第一版只显示“配置 / AI 模型”有效入口。
- 右侧内容区显示一个“AI 模型”页面和一张配置卡片。
- 配置卡片只包含：Base URL、API Key（密码输入）、模型名称、当前连接状态、保存配置按钮。
- 设置页不显示 AI 对话右栏，以保留参考图的宽内容区。
- 设置工作区与一级业务导航状态正交；进入设置时原工作区保持挂载，返回后保留智剪编辑状态和 AI 会话状态。

## 数据流与安全

页面加载时调用已有 `window.api.getAgentModelStatus()`，只回填 `baseUrl`、`model` 和配置状态。API Key 永远不从 Main 返回；输入框只接受本次保存时的新 Key。

点击保存时调用已有 `window.api.configureAgentModel({ baseUrl, apiKey, model })`。保存成功显示“已配置”，失败显示 Main 返回的错误消息；不做额外网络探测。API Key 不写入 Renderer 持久化，也不显示在状态文本中。

## 面板边界

AI 面板的设置按钮跳转到设置工作区，不再承担全局模型配置。会话消息、附件和会话级操作仍属于 AI 面板状态，不写入设置页。

## 验证

补充设置页表单、加载状态、保存成功/失败、侧栏导航和 AI 面板跳转测试；完成后运行 `npm test -- --reporter=dot`、`npm run typecheck`、`npm run build`、`npm run lint` 和 `git diff --check`。
