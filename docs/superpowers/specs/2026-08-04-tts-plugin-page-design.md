# 插件页与本地 TTS 插件设计

## 目标

在现有桌面客户端中增加独立的“插件”入口和插件管理页。`TTS 配音`继续作为用户直接使用的工具；本地离线配音能力作为可按需安装的插件，由插件页统一管理。

这次不建设通用的第三方插件运行时，也不改变现有 Electron 主进程、preload 和 sherpa-onnx TTS 链路。插件页是现有本地 TTS 资源管理能力的产品化入口。

## 产品定义

- `TTS 配音`是工具：负责输入文本、选择语言和音色、试听、生成与保存音频。
- `本地 TTS 配音`是插件：负责离线配音能力的安装状态、资源下载和卸载。
- Kokoro、Supertonic 等技术名称属于内部实现，不在 TTS 配音页展示。
- 用户需要管理资源时进入插件页；日常配音不需要理解模型概念。

## 导航与页面结构

### 左侧菜单

在现有主菜单中新增“插件”，使用标准 Lucide 插件图标。菜单顺序为：

1. 首页
2. 小说推文
3. TTS 配音
4. 插件
5. 智剪（仅开发环境）

点击“插件”后由现有 `WorkspaceView` 渲染独立的 `PluginsView`，保持工作区导航状态与智剪编辑器状态相互独立。`PluginsView` 内部维护“插件列表 / 插件详情”两级页面状态，不新增侧栏菜单。

### 插件页顶部

参考用户提供的页面布局，在中间内容区顶部展示：

- `插件 / 技能`页签；插件页默认选中“插件”。
- 标题“插件”。
- 说明“安装本地创作能力，让常用工具按需扩展”。
- 搜索框，支持按插件名称和说明过滤。

“技能”页签保留完整可点击状态，首版展示空状态，不放置无响应的假按钮。

### 插件列表

页面分为“已安装”和“可安装”两部分，条目使用参考扩展市场的紧凑列表，不套用多层卡片。列表项由两个互不嵌套的交互区域组成：

- 主体区域包含图标、名称、说明和状态；点击主体或其空白区域进入插件详情页。
- 操作区域只负责安装或卸载，不触发详情页导航。

首版只提供一个插件：

- 名称：本地 TTS 配音
- 说明：在电脑本地完成文本配音，内容无需上传服务器
- 状态：未安装、安装中、已安装或安装失败
- 未安装操作：显示“安装”按钮；点击后只开始安装。
- 已安装操作：显示齿轮图标；点击后打开小型菜单，菜单内提供“卸载”。
- 安装失败操作：显示“重试”按钮。
- 安装中操作：显示加载状态并禁用重复操作。

列表不再行内展开语音资源，也不再显示“管理”按钮。无论插件是否安装，点击列表主体都可以进入详情页。

### 插件详情

详情页顶部显示面包屑 `插件 > 本地 TTS 配音`，点击“插件”返回列表。主体展示插件图标、名称、简介和状态：

- 未安装时显示“安装”按钮。
- 已安装时显示齿轮图标，菜单内提供“卸载”。
- 不显示“打开配音”按钮。

详情页下方展示“语音资源”和“信息”两个无卡片嵌套的列表区。语音资源以用户可理解的名称展示现有三类资源：

- 中文高品质音色
- 中英通用音色
- 多语言音色

这些名称分别映射到现有 TTS 模型目录项，下载、进度和删除继续调用已有 preload API。未安装资源显示“安装”，已安装资源显示齿轮菜单并提供“卸载”，失败资源显示“重试”。资源操作不会返回插件列表。

“信息”区只显示用户需要理解的产品信息，例如本地离线处理、文本不上传服务器和资源占用；不展示模型名称、模型目录或底层引擎。

## 安装与状态规则

- 没有任何本地语音资源时，插件状态为“未安装”。
- 至少安装一个语音资源后，插件状态为“已安装”。
- 主列表的“安装”默认安装“中文高品质音色”，符合客户端当前主要使用语言。
- 详情页允许按需安装或删除其他语音资源，并显示下载大小、进度、失败信息和重试操作。
- 删除最后一个资源后，插件恢复“未安装”状态。
- 下载期间禁用重复安装与删除操作，但不阻塞页面搜索和页签切换。

## TTS 配音页调整

- 完全移除“本地语音模型”标题、说明和模型卡片。
- 音色列表聚合当前语言下所有已安装资源的可用音色。
- 用户选择音色后，由音色自身的 `modelId` 自动确定底层生成资源，不再要求用户选择模型。
- 当前语言没有可用资源时，显示紧凑提示“当前语言需要安装配音插件”，并提供“前往插件”按钮。
- 点击“前往插件”切换到插件页，不在 TTS 配音页直接管理下载或删除。

## 数据流

1. `PluginsView`通过 `window.api.listTtsCatalog()`读取现有资源目录，并把数据与操作回调传给列表页或详情页。
2. 页面将多个模型状态聚合成一个“本地 TTS 配音”插件状态。
3. 安装和删除继续调用 `installTtsModel()`与 `removeTtsModel()`。
4. 下载进度继续通过 `onTtsModelDownloadProgress()`更新。
5. 安装状态改变后重新读取目录，列表页与详情页同步显示新状态；TTS 配音页下次进入时自动使用新的音色资源。
6. 列表与详情切换只发生在 React 状态中，不新增 Electron IPC 或后端路由。

首版不新增 Java 后端接口，不上传文本，也不引入新的插件包格式。

## 错误与空状态

- 目录读取失败：在插件列表区域显示错误与“重新加载”。
- 下载失败：保留失败状态和“重试”，不把失败项误判为已安装。
- 搜索无结果：显示“没有找到相关插件”。
- 技能页签：显示“暂无可用技能”。
- 当前语言无音色：TTS 配音页只引导前往插件页，不显示底层模型错误。

## 视觉约束

- 参考图只用于页面信息层级，不复制 ChatGPT 品牌样式。
- 沿用项目现有浅灰侧栏、白色内容区、蓝色主操作色和 Lucide 图标。
- 页面顶部保持足够留白，但不使用营销式大标题、渐变宣传图或装饰性卡片。
- 列表行尺寸稳定，安装状态、进度和按钮变化不得引发布局跳动。
- 插件列表参考扩展市场的紧凑行布局；详情页参考面包屑、插件头部、能力列表和信息列表的层级，但不复制 ChatGPT 或 VS Code 品牌。
- 页面在现有可调整三栏布局的最小内容宽度下仍可滚动且不重叠。

## 测试范围

- 侧栏显示“插件”，点击后正确选中并打开插件页。
- 插件页顶部页签、标题、说明和搜索框符合可访问性语义。
- 搜索可以过滤插件；技能页签可以切换并显示空状态。
- 未安装状态点击“安装”会调用默认资源 ID，且不会进入详情页。
- 已安装状态点击齿轮会打开卸载菜单，且不会进入详情页。
- 点击列表项的图标、名称、说明或空白主体区域进入详情页。
- 面包屑可以从详情页返回插件列表。
- 详情页不显示“打开配音”按钮。
- 详情页可以安装或删除单项语音资源。
- 下载进度、失败和重试状态正确显示。
- TTS 配音页不再出现“本地语音模型”和具体模型名称。
- 多个已安装资源的音色能够聚合，生成请求使用所选音色对应的模型 ID。
- 当前语言无资源时可以从 TTS 配音页跳转到插件页。

## 非目标

- 第三方开发者插件 SDK。
- 在线插件市场、账号同步、付费或远程审核。
- 动态加载任意 JavaScript 插件代码。
- 修改现有本地 TTS 推理、长文本分段、WAV 合并和保存逻辑。
