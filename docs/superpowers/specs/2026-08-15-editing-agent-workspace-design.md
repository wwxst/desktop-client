# 剪辑 Agent 工作台设计

> 状态：当前实现设计
> 适用范围：首页 AI 对话工作区
> 日期：2026-08-15

## 产品定位

首页是全尺寸剪辑 Agent 工作台，不是右侧附属聊天栏。用户以自然语言发起视频剪辑任务，后续剪映 5.9 的计划、审批、执行进度、结果和人工接管也应沿同一对话时间线呈现。

内置智剪、多轨时间线和旧 AI 面板不恢复。剪映 5.9 是计划中的受控执行环境，Renderer 不直接获得桌面控制、文件系统或进程能力。

## 当前实现

- 空白态展示核心提问和四个视频任务快捷入口；点击只填入输入框，不自动发送。
- 对话态将用户消息靠右、Agent 回复靠左，并提供复制消息操作。
- 输入区固定在工作区底部，展示项目、剪映版本、权限控制和模型选择。权限菜单提供“请求批准”“智能审批”和“完全访问权限”，默认使用“请求批准”并在 Renderer 本地保存偏好。
- 模型配置来自 `window.api.listAgentModelConfigurations`，默认选择上次仍有效的配置，否则回退到第一项。
- 发送通过 `window.api.runAgentChat` 使用用户/助手交替的纯文本契约；当前不声明或执行任何工具。
- 页面明确显示“未选择项目”和“剪映 5.9 未连接”。权限偏好当前不进入纯文本聊天请求，待剪映执行契约接入后再用于工具审批，避免把未来能力表达成当前事实。
- 未配置模型时提供设置入口；从设置返回后重新加载模型列表。
- 左侧栏参考任务型 Agent 产品的信息密度，使用“剪辑 Agent”品牌头部、“新任务”主入口和“制作工具”分组；制作工具下方依次放置“项目”和“对话”分组。两个分组均提供更多菜单和新增按钮，共享“按项目 / 在一个列表中”的整理方式，并分别保存排序选择。项目通过 Main 原生目录授权创建本地目录、`project.json` 和全局索引，侧边栏启动时恢复已保存项目；对话新增按钮复用现有新任务重置逻辑，对话历史仍未持久化。

## 后续边界

剪映工具接入后，Agent 只能提交注册的高层视频任务动作。Main 侧 Adapter 负责版本检查、参数校验、草稿备份、原子替换、回滚、UI Automation 和输出验证。执行权限、审批和任务状态需要独立契约，不能扩展当前纯文本聊天请求或恢复旧编辑器工具协议。

## 验证

组件测试覆盖欢迎态、安全上下文、快捷任务、模型选择、多轮对话、新建会话和无模型设置入口。桌面窗口还需验证不同内容宽度下的卡片换行、输入区稳定尺寸、消息滚动和无重叠。
